Communications — Sanctioned Channels

Contact

All communication with Inner Context passes through sanctioned channels. Choose the one appropriate to your inquiry.

Section 1 — Available Channels

How to Reach Us

Each channel serves a specific purpose. Please direct your message accordingly.

01

Bug Reports

Something is not working as described. A desk is missing. A message arc is not rendering. The sphere has stopped rotating. File an issue on GitHub and include reproduction steps.

Open Issue →
02

Feature Requests

You have an idea for the office. A new visual. A different way to render status. A sound when messages arrive. We welcome proposals through GitHub Issues. Describe what you envision and why it matters.

Propose Feature →
03

General Inquiry

Questions about the project, collaboration proposals, or anything that does not fit the other channels. Reach out through GitHub or the founder's personal site.

Visit GitHub →
Every message passes through a sanctioned channel. Yours is no different. We read every one. We respond through the same channels you used to reach us. Inner Context, Department of External Communications
Section 2 — Contributions

Open Source Contributions

All Inner Context software is open source. If you want to improve the office, the plugins, or the documentation, pull requests are welcome.

The repositories are organized under the Inner Context GitHub organization. Each plugin has its own repository. WaterCooler has its own. Fork what interests you. Build what you think is missing.
